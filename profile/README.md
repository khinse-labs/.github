# khinse-labs

khinse-labs is a small organisation that builds software in the open where it can. Its repositories follow a shared set of conventions:

- Conventional Commits
- short-lived branches
- squash merges
- every change through a pull request

The shared files and automation live in [khinse-labs/.github](https://github.com/khinse-labs/.github), and apply to every repository in the organisation.
